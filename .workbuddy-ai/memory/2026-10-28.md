### 关键技术决策（后续改动需保持一致）

1. **状态机用 `int _state` + `Volatile.Read` / `Interlocked.Exchange` / `CompareExchange`**。
   不用 `volatile SerialConnectionState`：`volatile` 解决不了条件更新，且对 volatile 字段取 `ref` 传
   `Interlocked` 会报 CS0420。`TryFinishClose` 用 CAS 保证"只有还停在 closingState 才允许切 Disconnected"。
2. **`OpenAsync` 里 `new SerialPort(...)` 必须在 try 内**，否则构造抛异常会让状态永久停在 `Connecting`
   （原 P0：界面全禁用且只能重启）。
3. **服务层所有 `await` 加 `ConfigureAwait(false)`**，否则无竞争时 `WaitAsync` 同步完成会让
   `serial.Open()` 继续跑在 UI 线程上。
4. **关闭串口软超时 1.5s / 硬超时 6s**：软超时保持 `Disconnecting` 并等后台补完（绝不提前宣布
   Disconnected，否则重开必报端口占用）；硬超时降级 `Faulted`。
5. **接收队列 `Channel.CreateBounded(512, FullMode.Wait)`**，配合 `TryWrite` 返回 false 精确记账丢弃量。
6. **接收区显示管线**：VM 持有 `StringBuilder _displayBuffer`（上限 1,000,000，超限裁到 800,000），
   通过 `DisplayAppendRequested` / `DisplayResetRequested` / `DisplayCleared` 三个事件驱动 View。
   裁剪用"整体重设"而非"按字符数裁剪"，因为 WPF 换行归一化会导致两侧长度漂移。
   清空用 `_displayGeneration` 计数防止在途 flush 把旧数据写回。
7. **`Decoder` 只在消费线程使用**，UI 线程切换 HEX 模式时只置 `_resetDecoderPending` 标志。
8. **统计计数改为 VM 侧 `DispatcherTimer` 200ms 拉取**，值不变不发通知；服务层不再发统计事件。
9. **`_lifecycleGate` / `_writeGate` 故意不 Dispose**：释放时可能仍有 fire-and-forget 任务在 `WaitAsync`。
10. **`WriteAsync` 用 `serial.Write` 而非 `BaseStream.WriteAsync`**，以让 `WriteTimeout=1000` 生效。

## 界面改版（哆啦A梦主题）

### 哆啦A梦元素落点

1. **`DoraemonFace` DrawingImage** —— 矢量头像，复用于：页眉 Logo(50px)、接收区空状态水印(74px, 10% 透明度)。
2. **`BellIcon` DrawingImage** —— 铃铛，用于底部状态栏(15px)。小尺寸下比头像可辨识。
3. **应用图标 `Assets/app.ico`** —— Pillow 脚本绘制，多尺寸 16~256，通过 `ApplicationIcon` 嵌入。
   脚本思路：100×100 设计坐标 × 缩放，1024 画布超采样后存 ICO。
4. **配色** —— 主色为哆啦A梦身体蓝；连接后按钮转红；连接中/断开中指示点为铃铛黄。
5. **胶囊化复选框** —— 圆角药丸 + 圆点，呼应铃铛/项圈造型。

### 关键实现要点

- **不设 `DropShadowEffect`**：WPF 中父元素带 Effect 会关闭子树 ClearType，正文变灰糊。改用浅边框 + 背景层次。
- **圆角输入框**由外层 `Border` 提供，`TextBox` 本身 `Background=Transparent` / `BorderThickness=0`，
  避免自定义 TextBox 模板（`PART_ContentHost`）破坏 `ScrollToEnd()` 与滚动行为。
- **ComboBox / Button / CheckBox** 使用完整 `ControlTemplate`。ComboBox 的 Popup 内用
  `{TemplateBinding ActualWidth}` / `{TemplateBinding MaxDropDownHeight}`（与 WPF 原生模板一致）。
- **连接按钮变色**改用 `Style.Triggers` + `DataTrigger`（`IsOpenPort`），不再绑 `Background` 转换器。
- **状态指示点**用 `DataTrigger` 绑新增的 `ConnectionState`（枚举，`{x:Static model:SerialConnectionState.X}`）。
- `ConnectionStatus` 文案去掉了 `●`/`○` 前缀，改由胶囊里的圆点表达。
- 发送区占位提示用 `DataTrigger Binding="{Binding SendText}" Value=""` 控制可见性。
- 空状态水印显隐由 code-behind 在 `DisplayAppend/Reset/Cleared` 三处切换 `EmptyHint.Visibility`。

## 分发打包（自包含单文件）

### 背景
原产物 `bin/Debug/net10.0-windows/SerialAssistant.exe` 仅 218KB，是**框架依赖**版，
目标机器必须装 .NET 10 桌面运行时。给没有开发环境的朋友用必须改为自包含。

### 配置

新增 `Properties/PublishProfiles/win-x64.pubxml`，一条命令重新打包：

```
dotnet publish -p:PublishProfile=win-x64
```

关键参数：
- `RuntimeIdentifier=win-x64` + `SelfContained=true`
- `PublishSingleFile=true` + `IncludeNativeLibrariesForSelfExtract=true`
  （System.IO.Ports 有 native 依赖，不加后者单文件会缺 DLL）
- `EnableCompressionInSingleFile=true`
- `DebugType=none`
- `PublishDir=publish\win-x64\`

**WPF 不支持 NativeAOT，也不支持 PublishTrimmed**（会裁掉 XAML 反射所需信息），
所以 59MB 是体积下限，不要再试图用 Trim 瘦身。

### 产物
- `publish/win-x64/SerialAssistant.exe` —— 59.0 MB 单文件，内含运行时
- `publish/win-x64/使用说明.txt` —— 给使用者的说明（UTF-8 带 BOM）
- `publish/串口助手-Doraemon-win64.zip` —— 53.6 MB，发给朋友的最终包

### 顺带补充的工程元数据（`SerialAssistant.csproj`）

`AssemblyTitle` / `Product` / `Description` / `Version=2.0.0` / `AssemblyVersion` / `FileVersion`。
分发前这些是空的，右键属性一片空白。注意 `CompanyName` 仍会默认取程序集名 `SerialAssistant`。

### 验证
解压到干净目录后直接运行 → 窗口正常渲染（截图核对），无 .NET 环境依赖。
